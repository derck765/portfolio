    Med Tracker

    About the Project

    An android application that allows users to track their medications, track symptoms, set reminders for medication, and share their medical information with their doctors. Additionally, the app allows users to "test interactions" between medications that are on their list. By using RxNorm API and RxCUI API, the app is able to convert generic brand names, such as tylenol, into their corresponding drug name and RxCUI codes, which are then used to check for possibly harmful interactions between medications via Gemini API.

    Languages, Frameworks, and Libraries

    Kotlin
    Android Studio

    RxCUI API

    Trash Dash

    About the Project

    This was the first "big" project I ever worked on so it holds a special place in my heart. My friend and I developed this game together during my senior year of highschool for the national "game for change" competition of 2022. The goal of the game was to raise awareness about environmental issues and promote sustainable practices. We approached this by making a 2D platformer game where the player's goal is to collect trash around cities and neighborhoods while avoiding spikes and other obstacles. Upon completion of the game, a message is displayed to the player about the importance of keeping our environment clean and how they can make a difference in their own communities.
